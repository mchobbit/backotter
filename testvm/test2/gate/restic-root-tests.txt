# root (testvm/test2/gate/fork-root.sh): the tests whose skip message, when
# testvm/audit/fork-tests.sh runs the suite as m, says root is needed ("needs
# root", CAP_LINUX_IMMUTABLE, "operation not permitted").  The rest of the
# suite stays m's.  Only these run as root; a new one runs once it is reviewed
# and listed here.  fork-root.sh fails its root-list need for any such skip
# that is neither a "run" nor an "out" line.
#
#   run PACKAGE TEST   # what it mounts or writes, and that it touches only
#                      # loop devices and temporary files it makes itself
#   out PACKAGE TEST   # why it stays out
#
# Reviewed against restic 5253b20 (branch backotter, 0.19.1+backotter.5) on
# 2026-11-08: 14 tests.  Every temporary directory below is rtest.TempDir or
# t.TempDir, both under TMPDIR, which fork-root.sh points at its reserved RAM
# directory; every image is a sparse file there, mounted with mount -o loop
# (the loop device mount sets up, freed again by umount) or a tmpfs mounted
# below that directory; every one is unmounted by the test's cleanup, and
# fork-root.sh unmounts and detaches by path what is left under that
# directory.  None needs a network, a pool, a guest or a device of the host.
#

# mkfs.ext4, chattr and lsattr in /usr/sbin and /usr/bin; bcachefs (format,
